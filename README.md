
# Quiz en images - Application Android

## 1. Présentation du projet

Ce projet consiste à développer une application Android de quiz en images.
L'utilisateur doit répondre à cinq questions illustrées en choisissant une réponse parmi trois propositions.

L'application calcule le score, affiche la progression et présente le résultat final à la fin du quiz.

## 2. Objectifs

- Créer une interface Android avec XML.
- Programmer la logique de l'application en Kotlin.
- Afficher une image pour chaque question.
- Gérer les réponses de l'utilisateur.
- Calculer le score et mettre à jour la progression.
- Afficher le résultat final et permettre de rejouer.

## 3. Technologies utilisées

- Android Studio
- Kotlin
- XML
- Android SDK

## 4. Fonctionnalités

- Cinq questions illustrées.
- Trois choix de réponse par question.
- Calcul automatique du score sur 5.
- Barre de progression.
- Message indiquant si la réponse est correcte ou incorrecte.
- Affichage du résultat final.
- Bouton Rejouer pour recommencer le quiz.

## 5. Structure du projet

- `MainActivity.kt` : logique du quiz.
- `activity_main.xml` : interface utilisateur.
- `res/drawable/` : images utilisées pour les questions.
- `captures/` : captures d'écran de l'application.
- `compte-rendu/` : compte rendu du TP.

## 6. Installation et lancement

1. Télécharger ou cloner le dépôt GitHub.
2. Ouvrir le projet dans Android Studio.
3. Attendre la synchronisation Gradle.
4. Lancer l'application sur un émulateur Android ou un téléphone compatible.

## 7. Tests réalisés

- Vérification d'une bonne réponse.
- Vérification d'une mauvaise réponse.
- Vérification du score.
- Vérification de la progression.
- Vérification du résultat final.
- Vérification du bouton Rejouer.

## 8. Captures d'écran

Les captures d'écran de l'application sont disponibles dans le dossier `captures/`.
